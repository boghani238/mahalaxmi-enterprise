MAHALAXMI ENTERPRISE - GITHUB PAGES WEBSITE

Files:
- index.html           Main website
- privacy-policy.html  Privacy policy page

Publish on GitHub Pages:
1. Create a public repository named mahalaxmi-enterprise.
2. Upload both HTML files to the repository root (not inside another folder).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch: main; folder: /(root), then Save.
6. Wait for GitHub Pages to publish the site.

Expected URLs:
https://YOUR-GITHUB-USERNAME.github.io/mahalaxmi-enterprise/
https://YOUR-GITHUB-USERNAME.github.io/mahalaxmi-enterprise/privacy-policy.html

The app download link is set to:
https://play.google.com/store/apps/details?id=com.mahalaxmi.universaltvremote

IMPORTANT:
Review the privacy policy against the actual permissions, ad SDKs, analytics SDKs,
and data collection practices in the published app before using it for Play Console.
